# 设备管理 · 内容与交互

## 身份与分类

示例设备“V5测试的小乐”，主人昵称“V5测试”。切换设备按钮、名称旁编辑图标和复制图标均未实现业务操作。

基础设置和系统参数通过页内选项卡切换，同属设备管理路由。默认基础设置。返回按钮进入成长中心首页。

## 基础设置

| 项目 | 当前内容与行为 | 待确认 |
| --- | --- | --- |
| 设备电源 | 展示“小乐正在睡梦中，请开机~”“关灯”“已关机”，没有操作行为 | 开关机与灯光控制是否分开、真实状态与失败反馈 |
| 网络 | 展示“网络断开”“未连接”“网络设置”，没有配网行为 | 网络类型、配网流程、断线/重连与错误状态 |
| 主动对话 | 默认开启；静默默认 30 秒；滑杆范围 10–60 秒，步进 10 秒；说明攀谈总次数为 3 次 | “静默”计时起点、3 次计数重置、配置下发与权限 |
| 接话速度 | 默认开关关闭、速度第 3 档；开关只改变显示状态，滑杆仍可操作；范围 1–5 | 关闭后滑杆是否禁用、实际档位含义与生效方式 |
| 音量 | 默认第 3 档，范围 1–5，端点文案“哄睡”“响亮”，显示“调节后需重新开机” | 实际音量映射、是否需重启、执行失败回滚 |

主动对话关闭时展示“已关闭”，说明与标签变淡，频次滑杆禁用；重新开启保留当前演示间隔。开启状态在页面与状态面板中同步。

主动对话滑杆允许 50 秒，但当前刻度只列 10、20、30、40、60 秒。音量中间档位为“较弱、正常、较强”。这些是当前实现事实，待产品确认是否保留，标注阶段不擅自改变。

## 系统参数

示例值：设备 ID 为 `14:c1:9f:d6:e7:84`，版本 `1.1.5`，陪伴时长 `39天`。提示设备 ID 可供客服定位问题。复制图标目前不复制。

解除绑定入口只展示，没有确认弹窗、设备解绑、数据清理或成功反馈。其权限、二次确认、成长数据保留、离线处理和失败重试均待确认。

## 演示状态边界

状态标注只接入已有菜单、选项卡、开关、间隔和档位，不新增“联网成功”“开机成功”等未经确认的业务状态。演示不会调用设备 API。
