# 状态目录与待确认事项

## 已接入状态

| 位置 | 状态控件 | 默认值 | 页面效果 |
| --- | --- | --- | --- |
| 首页设备操作区 | 菜单展开开关 | 收起 | 切换已有功能菜单；外部点击收起 |
| 设备设置分类 | 基础设置 / 系统参数 | 基础设置 | 只显示当前分类内容及对应标记 |
| 主动对话 | 开关、静默间隔 | 开启、30 秒 | 关闭时禁用频次滑杆；开启时显示当前间隔 |
| 接话速度 | 开关、1–5 档 | 关闭、第 3 档 | 切换开关外观或滑杆位置 |
| 音量 | 1–5 档 | 第 3 档 | 切换滑杆位置 |

目录中的菜单展开、基础设置、主动对话关闭、系统参数入口可切换对应页面和已有状态。控件只控制前端演示值，无硬件写入行为。展示电源和网络的状态属于固定示例，没有可切换成功/失败控件。

## 产品待确认

1. 成长阶段与建议的来源、年龄划分、昵称/头像字段；加载、空数据、异常和超长文本的完整规则。
2. 童言拾光的目标页面、记录方式、徽标“4”的统计含义、零条记录时的表现。
3. 成长报告是否独立成页；各工具、客服、菜单项与底部导航的真实去向。
4. 设备添加、切换、编辑、复制、解绑的操作权限、确认与成功/失败流程。
5. 灯光与开关机语义、联网状态、配网路径、设备 API 的数据来源。
6. 主动攀谈 3 次的计数周期与重置规则；50 秒是否为合法档位及刻度表现。
7. 接话速度关闭是否仍能调档；接话速度与音量映射；“需重新开机”是否属真实生效规则。
8. 页面切换与刷新后的配置持久化、设备同步失败回滚、加载和保存反馈。
9. “灵玛乐园”“灵玛星球”“阿乐”的命名关系；可共享的外部产品需求资料链接。
