# 灵玛星球设计规范

版本：v1.0 · 2026-10-10  
事实源：用户确认的品牌色彩视觉规范、字号与尺寸要求；现有灵玛星球原型和参考截图用于页面语境补充。

## 1. 视觉主题与氛围

灵玛星球是面向家长和儿童陪伴场景的移动端小程序。视觉应传达“温暖、可信、轻松、可持续陪伴”，同时保留设备管理所需的清晰信息层级。

- 关键词：自然绿、亲子温度、柔和留白、轻量硬件、清晰状态。
- 页面气质：首页偏温暖和有故事感；设备管理页偏安静、克制、易扫描。
- 信息密度：以单列移动端为默认，卡片内保持 16px 以上可读留白；设备参数允许密集分组，但不堆叠装饰。
- 适用：成长中心、设备管理、成长报告、家长设置、陪伴状态和轻量反馈。
- 不适用：高饱和霓虹、强烈渐变、游戏化复杂装饰、全屏深色后台、过重拟物阴影。

### 2.2 使用边界

- 主色路径：`green-400` 用于主要操作和积极状态，`green-500` 用于文字、图标和链接。
- 橙色只表达提醒、未读、情绪或需要关注的状态；不要用橙色承载主导航或主要提交操作。
- 页面默认使用 `gray-50` 或暖白背景，内容卡片使用 `gray-0`；文本优先 `gray-700`，辅助说明用 `gray-500` 或 `gray-400`。
- 渐变只允许用于 Hero 或推荐浅底，方向由 `green-100` 向 `green-800`，或 `orange-100` 向 `orange-200`；禁止彩虹、霓虹和大面积高对比渐变。
- 文字与背景必须满足可读对比度；`green-300`、`orange-300`、`yellow-300` 不直接承载小字号正文。

## 3. 字体系统

字体族：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`。不引入装饰性字体；数字和设备 ID 可使用 `ui-monospace`。

| 角色 | 尺寸 | 行高 | 字重 | 用法 |
| --- | ---: | ---: | ---: | --- |
| 一级标题 | 20px | 1.4 | 700 | 页面标题、核心卡片标题 |
| 一级正文 | 16px | 1.5 | 400-600 | 主要内容、按钮文字 |
| 二级正文 | 14px | 1.55 | 400-500 | 辅助内容、表单说明 |
| 按钮文字 | 16px | 1 | 600-700 | 开关旁标签、弹窗操作按钮 |
| 最小正文 | 12px | 1.45 | 400-500 | 徽标、次要状态、底部导航辅助文字 |

允许在大屏演示或大型插画标题中使用 24px，但移动端业务正文不超过 20px。中文与英文混排不使用负字距，默认字距为 0。

## 4. 组件规范

### 开关按钮

- 尺寸固定为 `50×30px`，圆角 `25px`；这是“按钮”默认指代的开关控件。
- 轨道开启使用 `green-400`，关闭使用 `gray-300`；滑块为 `gray-0`，直径 22px，内边距 4px。
- 开启滑块向右移动 20px；状态必须同时有可读文本或 `aria-label`，不能只依赖颜色。
- 禁用态降低对比度并禁止拖动；focus-visible 使用 2px `green-300` 外环。

### 弹窗操作胶囊

- 确定、取消等弹窗操作按钮不使用 50×30 开关规格，使用高度 36px、圆角 `28px` 的胶囊按钮。
- 字号 16px、字重 600；主操作为 `green-400` 白字，次操作为 `green-100` 或白底 `green-500` 字。
- 横向内边距 16px，最小可触达宽度 80px；两个按钮间距 8px。

### 通用胶囊、徽标与输入

- 胶囊高度 `36px`，圆角 `18px`（上限 28px），用于筛选、状态、切换和短操作；字号 14px，重要操作可用 16px。
- 徽标高度 `20px`，最小宽度 20px，圆角 10px；数字徽标使用 `orange-400`，文字徽标使用 `green-500` 或中性色。
- 输入框高度 44px，圆角 12px，边框 `gray-200`；聚焦边框 `green-400`，错误边框 `orange-500`。

### 卡片、导航与弹窗

- 卡片默认白底、圆角 20px；设备身份卡和大型成长摘要卡可使用 24px，禁止超过 28px。
- 底部导航为白色固定表面，上边框 `gray-200`；当前项使用 `green-400`，未选中项使用 `gray-400`。
- 弹窗宽度固定 `320px`（视口不足时左右各留 16px），圆角 20px，内边距 20px；遮罩使用 `rgba(31,35,33,.32)`。

### 图标和插画

- 图标优先使用圆角线性风格，常规尺寸 20px，主要操作 24px；线宽保持 1.8-2px。
- 插画只承担情绪和引导，不承载关键数据；不得遮挡标题、按钮或底部导航。

## 5. 布局与间距

- 默认设计宽度为 375-428px，页面内容左右内边距 16px；宽屏容器最大 750px 并居中。
- 使用 4px 基准间距：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48px`。
- 页面级分区间距 24-32px，卡片内间距 16-20px，列表项之间 8-12px。
- 首页采用“顶部状态与品牌区 → 成长摘要 → 工具面板 → 底部导航”的单列节奏；设备页采用“设备身份 → 基础设置 → 参数设置”的分组节奏。
- 触控目标最小 44×44px；固定底部导航需为安全区留出至少 12px。

## 6. 深度、阴影与边框

| 层级 | Token | 用途 |
| --- | --- | --- |
| flat | 无阴影 | 默认内容卡片、列表、设置项 |
| raised | `0 4px 14px rgba(47,52,50,.06)` | 设备身份卡、工具面板 |
| floating | `0 10px 24px rgba(47,52,50,.10)` | 客服入口、浮层菜单 |
| modal | `0 18px 40px rgba(31,35,33,.16)` | 弹窗、关键浮层 |

边框默认 1px `gray-200`；分割线使用 1px `gray-200` 或 8% 黑色；不要使用粗描边、强黑投影、玻璃拟态模糊或装饰性发光。

## 7. 动效

- 默认过渡 160-220ms，使用 `cubic-bezier(.2,.8,.2,1)`；弹窗出现可用 240ms。
- 开关滑块只做水平位移；卡片 hover/focus 只改变边框、背景或阴影，不改变布局尺寸。
- 菜单和弹窗出现使用 opacity + translateY(4px)；退出反向播放并保持内容不跳动。
- 尊重 `prefers-reduced-motion: reduce`，关闭位移和非必要过渡。

## 8. 响应式行为

- 320-428px：单列布局，左右 16px，工具卡两列时每列至少 140px；空间不足时改为单列。
- 429-750px：保持单列主流程，卡片内部可两列排列；弹窗仍保持 320px 最大宽度。
- 751px 以上：内容容器最大 750px 居中；不得把移动端核心信息扩展成宽表格。
- 图片和插画使用 `object-fit: contain`，优先保持主体完整；底部导航在所有宽度固定于内容容器底部。
- 文字不可被裁切；长设备 ID、昵称和状态使用换行或省略号，并保留完整的辅助标签。

## 9. Prompt guide

### 推荐写法

1. “使用灵玛星球主题：`green-400 #52C873` 作为主操作色，`gray-50 #F7F9F8` 页面底色，白色卡片，移动端左右 16px。”
2. “按 20/16/14/12px 字号层级实现成长中心，按钮文字 16px；开关固定 50×30px，弹窗确定/取消使用 36px 高、圆角 28px 胶囊。”
3. “设备管理页采用白色圆角 20px 卡片和 4px 间距基准，状态清晰、阴影轻、信息密度适中。”
4. “弹窗宽度 320px，徽标高度 20px；焦点态和禁用态可见，并保证触控目标至少 44px。”

### 禁止写法

1. “随意选择高饱和紫色、霓虹色或深色渐变替代品牌绿。”
2. “把所有按钮都做成 50×30px”；该尺寸只适用于开关按钮。
3. “用大面积插画、重阴影或玻璃模糊遮挡设备状态和设置内容。”
4. “用 10px 以下文字、负字距或仅靠颜色表达状态。”

### 可直接复用的生成提示

> 为灵玛星球小程序生成移动端页面。遵循 `DESIGN.md`：自然绿为主色，暖白/浅灰为背景，白色圆角卡片；字号使用 20px 一级标题、16px 一级正文和按钮、14px 二级正文、12px 最小正文。开关固定 50×30px 圆角 25px；弹窗宽 320px，确定/取消为 36px 高、圆角 28px、16px 字号胶囊；徽标高 20px。保持信息清晰、触控目标至少 44px、轻阴影、无强渐变和无装饰性噪声。
